1. Objeto del servicio

Robot YouTube es una herramienta de software integrada en el ecosistema Oficina Central, diseñada para consultar, organizar y analizar información de canales de YouTube que el usuario autoriza expresamente.

4. Conexión con Google y YouTube

El usuario puede conectar sus propias cuentas de Google mediante el sistema oficial OAuth.

La aplicación no utiliza estos permisos para publicar, modificar o eliminar vídeos ni para alterar la configuración de los canales.

El usuario puede retirar los permisos concedidos desde la configuración de seguridad de su cuenta de Google.
