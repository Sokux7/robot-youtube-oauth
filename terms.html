Condiciones de uso

Última actualización: 26 de noviembre de 2026.

1. Objeto de la aplicación

Robot YouTube es una aplicación de escritorio destinada a consultar, organizar y analizar información y estadísticas de canales de YouTube autorizados expresamente por sus respectivos usuarios.

2. Acceso y autorización

Para utilizar las funciones de consulta de YouTube, el usuario debe conectar su cuenta mediante el sistema oficial Google OAuth y conceder los permisos correspondientes.

El usuario únicamente debe conectar cuentas y canales sobre los que tenga autorización legítima.

3. Autorización de instalación

El acceso a las funciones protegidas requiere una autorización válida de la instalación.

La autorización está vinculada al equipo que haya sido aprobado. Copiar los archivos de la aplicación a otro ordenador no transfiere automáticamente dicha autorización.

La autorización de una instalación no puede compartirse ni utilizarse para habilitar instalaciones no autorizadas.

4. Uso de las API de YouTube

La aplicación utiliza las API oficiales de YouTube Data y YouTube Analytics para consultar información y estadísticas de los canales autorizados.

Los permisos solicitados son de lectura. La aplicación no utiliza estos permisos para publicar, modificar o eliminar vídeos, comentarios ni configuraciones de los canales.

El usuario puede revocar los permisos concedidos desde la configuración de su cuenta de Google.

5. Responsabilidades del usuario

El usuario se compromete a:

  • Utilizar únicamente cuentas y canales sobre los que tenga autorización.
  • Mantener protegidas sus credenciales de acceso.
  • No utilizar la aplicación para acceder sin autorización a información de terceros.
  • Respetar las condiciones y políticas de Google y YouTube.

6. Propiedad intelectual

El código, estructura, documentación, diseños y materiales originales de Robot YouTube están protegidos por la legislación aplicable sobre propiedad intelectual.

No está permitida su copia, modificación, distribución, sublicencia o utilización fuera de las autorizaciones concedidas por el titular de los derechos.

7. Servicios externos

Algunas funciones dependen de servicios externos, especialmente Google, YouTube y sus API oficiales.

El uso de dichos servicios está sujeto a sus propias condiciones, políticas y limitaciones técnicas.

8. Disponibilidad y funcionamiento

No se garantiza la disponibilidad ininterrumpida de los servicios externos ni la obtención permanente de todas las métricas, ya que su disponibilidad depende de las API y de los permisos concedidos.

La aplicación proporciona herramientas de consulta y análisis. No garantiza resultados concretos de crecimiento, visualizaciones o suscriptores.

9. Suspensión de acceso

La autorización de una instalación podrá suspenderse o revocarse cuando se detecte un uso no autorizado, una vulneración de las condiciones o una distribución de archivos destinada a eludir los mecanismos de autorización.

10. Privacidad

El tratamiento de la información y los datos obtenidos mediante Google OAuth se describe en la Política de privacidad.

11. Condiciones de YouTube

El uso de Robot YouTube implica el cumplimiento de las Condiciones del Servicio de YouTube y de las Condiciones de los servicios de API de YouTube.
