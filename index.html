Robot YouTube

Robot YouTube es una herramienta de escritorio de uso personal para consultar y analizar el rendimiento de canales de YouTube autorizados por sus respectivos titulares.

La aplicación utiliza las API oficiales de YouTube y YouTube Analytics, mediante autorización OAuth de Google, para obtener información de canales y estadísticas de rendimiento. No está disponible comercialmente ni ofrece acceso público a sus funciones.

El acceso requiere la autorización explícita de cada cuenta de Google. Los permisos utilizados son exclusivamente de lectura y no permiten publicar, modificar ni eliminar vídeos.
